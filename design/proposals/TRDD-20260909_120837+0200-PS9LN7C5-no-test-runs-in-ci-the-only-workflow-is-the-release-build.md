# No test runs in CI because the only workflow is the cargo-dist release build

Filed as a proposal, not a task: it adds a workflow under `.github/`, which is the Tier-2 floor
in the approval rule. In this standalone project the user is the manager.

## What is known

- Measured 2026-09-09: `.github/` holds exactly one file, `workflows/release.yml`, generated by
  cargo-dist. It runs `dist build` steps and contains no `make` and no `cargo test`. The
  Makefile's `test` target (`cargo test -p tldr-core --lib`, `cargo test -p tldr-cli --lib`) runs
  only when someone types it. No pre-commit or lefthook config at the root. So the 1438 lib tests
  in `tldr-cli` alone, and every integration target, run by hand or not at all.
- Consequences already on the board: TRDD-9788CCBA (a test target compiled to zero tests and
  reported `ok` for weeks), TRDD-V7Q2KM8H (two more such targets), TRDD-N1VHRIN6 (an intermittent
  lib failure nobody has named), TRDD-GYNBICF9 (`make lint` red at HEAD, unnoticed).
- Constraint: `make check` is fmt + lint + test and lint is red today (GYNBICF9), so a job running
  `make check` would be red from its first run. `make test` alone is the honest first job.
  Integration targets are a separate decision: they take minutes and several are feature-gated.

## Proposed change

Add `.github/workflows/ci.yml`: triggers `pull_request` and `push` to `main`; top-level
`permissions: contents: read`; `concurrency` with cancel-in-progress; `timeout-minutes` on the
job; `actions/checkout` at its latest major and a SHA-pinned Rust toolchain action, both versions
checked with `gh api … /releases/latest` at authoring time; one step: `make test`. Nothing else
in the first version.

## Acceptance

- [ ] A workflow runs `make test` on push and pull_request; the URL of its first green run quoted.
- [ ] Least-privilege permissions, third-party actions SHA-pinned, `timeout-minutes` set.
- [ ] The follow-up decisions recorded here: lint in CI after GYNBICF9, and which integration
      targets (with which features) join, or why none do.
